# Local vision dependencies

The active person-only app path uses official Ultralytics YOLO26s COCO detections and Kaiyang Zhou's [OSNet-AIN](https://github.com/KaiyangZhou/deep-person-reid/tree/f8cd150fdf77e8d9e1ed143b7f308c2c609ded50) MSMT17 person re-identification weights. YOLO26s retains Ultralytics' AGPL-3.0 terms below. OSNet architecture and official weights are MIT licensed; the upstream license is retained in `licenses/OSNet-MIT.txt`. `osnet_ain.py` vendors only the inference architecture from that pinned source; automatic pretrained downloads are omitted. The official author-hosted weight URL, revision and SHA256 are pinned in `assets.json`; strict weights-only loading happens locally. Body descriptors are transient session evidence, not an identity database or calibrated identity probability. No camera frames are uploaded by model preparation.

The optional generic-object reference evaluator uses Ultralytics YOLOE-26n and the Ultralytics Python package, licensed upstream under AGPL-3.0, with an Enterprise licensing alternative. See the [upstream license](https://github.com/ultralytics/ultralytics/blob/main/LICENSE) and [model licensing](https://www.ultralytics.com/license). This notice does not change the license of existing GazeCore files. No source publication or distribution is performed by setup.

The two weights come from the official Ultralytics assets v8.4.0 release. URLs and SHA256 digests supplied by GitHub's release API are pinned in assets.json. The bus and Zidane images used for local acceptance tests are bundled upstream public sample assets. OpenCV, NumPy, PyTorch and Pillow retain their upstream licenses; installed distributions include their license files. Review upstream terms before distributing a derivative product.

NanoTrack v3 weights and the decoding algorithm come from HonglinChu's [NanoTrack project](https://github.com/HonglinChu/SiamTrackers/tree/248663fde6bf7c40190cf10ee396d5662919ecd3/NanoTrack), licensed under Apache-2.0. The implementation was adapted for OpenCV DNN/NumPy, native 15x15 outputs, and validation. The model URLs and locally computed SHA256 digests are pinned to that source revision. The upstream license is retained in licenses/NanoTrack-APACHE-2.0.txt. No private video or personal reference images are distributed.

The optional generic-object reference motion tracker uses Meta's [SAM 2.1 Tiny](https://github.com/facebookresearch/sam2/tree/2b90b9f5ceec907a1c18123530e92e794ad901a4), code and weights under Apache-2.0. The checked-in configuration and streaming step follow that pinned implementation. Original conditioning plus at most 16 recent accepted outputs are retained per camera; the shared model does not retain a complete recording. The original 1024-pixel configuration is loaded at 512 pixels after local quality/runtime comparison. MPS inference uses measured float16 autocast; CPU inference remains float32. The upstream license is retained in licenses/SAM2-APACHE-2.0.txt. NanoTrack is retained as a comparison/regression baseline and is not used by the person-only app path.

[DINOv2 ViT-S/14](https://github.com/facebookresearch/dinov2) official weights, under Apache-2.0, provide appearance evidence only for brief recovery. Pinned timm 1.0.22 constructs the inference architecture without downloading pretrained weights; strict loading omits only the unused training mask token. The upstream license is retained in licenses/DINOv2-APACHE-2.0.txt. Cosine similarity, object presence and predicted mask quality are different evidence scores, not calibrated instance-identity probabilities. The service uses no identity database. These models load only checksum-verified local assets; preparation does not upload any camera data.

[LoFTR](https://github.com/zju3dv/LoFTR) supplies local feature correspondences for cross-view acquisition through pinned [Kornia 0.8.3](https://github.com/kornia/kornia/tree/v0.8.3). Both use Apache-2.0; upstream license texts are retained in licenses/LoFTR-APACHE-2.0.txt and licenses/Kornia-APACHE-2.0.txt. The indoor-new checkpoint is pinned to Kornia's public model repository revision and checksum in assets.json. Inference constructs LoFTR with pretrained=None and strictly loads the verified local checkpoint; it never invokes Kornia's automatic model download. Grayscale contrast normalization and 320-pixel inference preserve bounded local computation. Geometric inlier ratios are consistency measurements, not identity probabilities. Private camera data remains local.

The cached coarse/fine correspondence adapter follows the pinned Kornia 0.8.3 LoFTR inference stages. Only pre-attention Scene CNN features are reused; cross-attention and fresh Target/masked-Target inference remain per observation. The above Kornia/LoFTR Apache-2.0 attribution and retained licenses apply. No additional model assets or network services are introduced.
